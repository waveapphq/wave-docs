##### REQ-3.4.2.5 Plugin documentation

Each plugin includes comprehensive documentation enabling users to understand plugin capabilities, parameters, behavior, and usage patterns through the GUI's context-sensitive help system and full documentation viewer.

**Structured Documentation Components**: Plugin documentation consists of multiple components addressing different information needs. Overview section describes what the plugin does and primary use cases. Parameter documentation details each input parameter with descriptions, types, constraints, and examples. Return value documentation explains what data the plugin produces and its structure. Behavior documentation describes how the plugin operates, side effects it may cause, and error conditions. This structured approach ensures documentation is comprehensive and accessible through the GUI.

**Context-Sensitive Inline Help**: Parameter schemas include inline documentation that appears contextually in the GUI during plugin configuration. Each parameter has a description field explaining its purpose in human-readable terms, answering "what is this parameter for" rather than just repeating the parameter name. When a user focuses on a parameter field while configuring a plugin in a block, the GUI displays the parameter's description, validation constraints, and allowed values as contextual help (tooltip, info panel, or inline text). For complex parameters, additional notes explain relationships with other parameters and provide guidance on value selection. This context-limited help keeps users focused on the immediate task without overwhelming them with full documentation.

**Full Documentation Viewer**: While configuring a plugin, users can open a dedicated documentation window displaying the plugin's complete documentation. This full view includes the plugin overview, all parameter details, return value specification, and behavior description. The documentation window remains accessible while configuring parameters, allowing users to reference detailed behavior descriptions as they work.
