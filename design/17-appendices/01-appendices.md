## 17. Appendices

### Appendix A: Technology Stack Summary
- **Backend**: Python 3.12+, FastAPI, Pydantic, AsyncIO
- **Frontend**: React 19, TypeScript, React Flow, Zustand
- **Storage**: YAML/JSON files
- **Testing**: Pytest, Vitest, Playwright
- **Build**: Poetry, Vite, Podman
- **Monitoring**: Custom logging

### Appendix B: Glossary
- **Block**: One step on a canvas: a plugin, a control or a Function
- **Function**: Reusable flow of Blocks with its own inputs and outputs
- **Plugin**: Executor providing specific functionality
- **Workflow**: Composed sequence of blocks
- **Suite**: Collection of related tests
- **Regression**: Collection of suites
- **Profile**: Connection configuration set
- **Artifact**: Execution output/result file
