# WAVE documentation

This repo holds the documentation for WAVE, the Workflow Automation and Validation Engine. The code is in [waveapphq/wave](https://github.com/waveapphq/wave).

There are three documents:

- **Solution description:** the problem WAVE solves and how it approaches it. Start here.
- **Requirements:** what WAVE must do. Each requirement has a number, such as REQ-3.1.3.14.
- **Design:** how WAVE works in the current release. Its sections carry the requirement numbers they answer, and its design decisions carry IDs, such as CANVAS-72.

The requirements are the source of truth. The design follows the requirements, and the code follows the design. Code and tests cite requirement numbers and design IDs, so those stay stable. Section numbers in the design have gaps; nothing depends on them.
